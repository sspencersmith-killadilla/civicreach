# CivicReach independent brand refresh

## What changes
- Remove every Civic Plexus mention from the interface, project documentation, and saved design direction.
- Replace the CR tile with a geometric connected-path mark and matching favicon/app icons.
- Align the visual system with BlockAid, Tandem, Relay, and Common Ground: Montserrat/Inter typography, paper-white surfaces, navy ink, teal-to-green accents, pill labels, and restrained rounded cards.
- Refresh the homepage, shared header, and footer while preserving the existing navy/teal/amber meaning and all city workflows.
- Correct the leftover `tandem` folder name in the self-hosting instructions.
